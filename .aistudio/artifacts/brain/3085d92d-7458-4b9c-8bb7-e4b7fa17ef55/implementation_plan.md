# แผนการแก้ไขการจัดเรียงความสูง: ป้องกันความสูงฮวบลงมา และบังคับการไต่ระดับความสูงต่อเนื่อง (Monotonic Ladder)

เอกสารแผนงานนี้จัดทำขึ้นเพื่อแก้ไขปัญหาความสูงของแถวสินค้าฮวบลงมาตรงช่วงรอยต่อระหว่างข้าว 5 กก. และข้าว 14/15 กก. ตามภาพจำลอง Side-View Visualizer ที่ผู้ใช้งานแจ้ง โดยจะปรับตรรกะการเกลี่ยความสูงในโหมด 3–5 รายการ ให้คิดคำนวณตามความหนาจริง (Physical Thickness Factor) เพื่อให้ความสูงรวมของทุกแถวไต่ระดับจากหน้ารถไปท้ายรถอย่างราบเรียบ ไม่มีแอ่งหรือหลุมยุบลงมา

---

## User Review & Critical Decisions

> [!IMPORTANT]
> สรุปข้อตกลงและเงื่อนไขที่ได้รับการยืนยันจากผู้ใช้งาน:

- **การควบคุมความสูงของข้าว 5 กก. เทียบกับ 14 และ 15 กก.**: ลดจำนวนชั้นของข้าว 5 กก. ลง (จากเดิม 9 ชั้น เหลือ 6–7 ชั้น) และเพิ่มจำนวนชั้นของข้าว 14 และ 15 กก. ขึ้น (เป็น 11–13 ชั้น) เพื่อชดเชยความหนาของกระสอบ (0.67 เท่า เทียบกับ 1.0 เท่า) ส่งผลให้ความสูงจริงไต่ระดับขึ้นอย่างสมดุล
- **การคุมความชันการไต่ระดับความสูง (Monotonic Ramp)**: บังคับให้ความสูงรวมเทียบเท่า (Total Height Factor) ของทุกแถวต้องเรียงลำดับจากเตี้ยไปสูงเสมอ ($h_1 \le h_2 \le \dots \le h_N$) ห้ามมีแถวใดที่เตี้ยกว่าแถวก่อนหน้าเด็ดขาด
- **การรักษาลำดับการวางสินค้า**: ยังคงยึดหลักการเดิมอย่างเคร่งครัด คือวางข้าว 5 กก. ให้หมดตามจำนวนก่อน จึงขึ้นข้าว 14 กก. และวางข้าว 14 กก. ให้หมดก่อนขึ้นข้าว 15 กก. ห้ามวางสลับไปสลับมา
- **การควบคุมระยะท้ายกระบะ**: บังคับระยะเหลือท้ายกระบะอยู่ในช่วงปลอดภัย **0–15 ซม. เสมอ**

## 1. Overview & Core Concept

- **สาเหตุของปัญหาในภาพ**:
  - ข้าว 5 กก. มีความหนา 1.0 เท่า (มัดละ 6 ถุง หนาแน่น) เมื่อวาง 9 ชั้น จะได้ความสูงเทียบเท่า **9.0 เท่า**
  - ข้าว 14 กก. และ 15 กก. เป็นกระสอบเดี่ยวที่มีความหนา 0.67 เท่า เมื่อระบบก่อนหน้าแบ่งให้วาง 9 ชั้นเท่ากัน จะได้ความสูงเทียบเท่าเพียง **$9 \times 0.67 = 6.0$ เท่า**
  - ทำให้ในภาพจำลอง กราฟิกแถวสีน้ำเงิน (5 กก.) พุ่งสูงถึงระดับ 9.0 แต่แถวสีเขียว (14 กก.) ฮวบลงมาเหลือระดับ 6.0 เกิดเป็นหน้าผาความสูงยุบลงมาตรงกลาง
- **แนวทางแก้ไขใหม่ (Physical Height-Proportional Stacking)**:
  - ในโหมด 3–5 รายการ (`plannerMultiSku.ts`) ปรับเปลี่ยนจากการเกลี่ยจำนวนชั้นเท่ากัน มาเป็นการเกลี่ยตามความสูงทางกายภาพจริง:
    1. **โซน 1 (1 กก.)**: 7–9 ชั้น (ความหนา 0.5) $\rightarrow$ ความสูงจริง **3.5 – 4.5 เท่า**
    2. **โซน 2A (5 กก.)**: 6–7 ชั้น (ความหนา 1.0) $\rightarrow$ ความสูงจริง **6.0 – 7.0 เท่า**
    3. **โซน 2B (14 กก.)**: 11–12 ชั้น (ความหนา 0.67) $\rightarrow$ ความสูงจริง **7.3 – 8.0 เท่า**
    4. **โซน 2C (15 กก.)**: 12–13 ชั้น (ความหนา 0.67) $\rightarrow$ ความสูงจริง **8.0 – 8.7 เท่า**
    5. **โซน 3 (40 กก.)**: 9–11 ชั้น (ความหนา 1.0) $\rightarrow$ ความสูงจริง **9.0 – 11.0 เท่า**
  - ทุกแถวจะมีความสูงไต่ระดับขึ้นอย่างต่อเนื่อง ไม่มีการฮวบลงมาแม้แต่นิ้วเดียว

## 2. User Experience & Visual Design

- **ภาพจำลองตัวรถด้านข้าง (Side-View Visualizer)**:
  - แนวระนาบของสินค้าจะเรียงเป็นขั้นบันไดลาดเอียงสวยงาม จากหน้ารถเตี้ยสุด ค่อยๆ ไต่ระดับขึ้นผ่านโซน 5 กก. $\rightarrow$ 14 กก. $\rightarrow$ 15 กก. $\rightarrow$ 40 กก. ท้ายรถ
  - แถวเชื่อมต่อ (Transition Rows) ที่มีการซ้อนขนาด (เช่น 5kg ฐานล่าง + 14kg ซ้อนบน) จะมีความสูงรวมที่เชื่อมระดับระหว่างแถวก่อนหน้าและแถวถัดไปอย่างไร้รอยต่อ
- **ตารางแจกแจงรายแถว (Row by Row Table)**:
  - แสดงจำนวนชั้นจริงของแต่ละ SKU อย่างสมเหตุสมผล เช่น ข้าว 5 กก. ซ้อน 6–7 ชั้น, ข้าว 14/15 กก. ซ้อน 11–13 ชั้น สอดคล้องกับพฤติกรรมการปฏิบัติงานจริงของพนักงานหน้าลาน

## 3. Technical Architecture & Implementation Strategy

```
┌────────────────────────────────────────────────────────────────────────┐
│               Height Calculation & Target Layer Logic                  │
├────────────────────────────────────────────────────────────────────────┤
│  1kg (หน้ารถ)  :  7-9 ชั้น   (หนา 0.5x)  =>  ความสูงจริง 3.5 - 4.5x      │
│  5kg (กลางหน้า):  6-7 ชั้น   (หนา 1.0x)  =>  ความสูงจริง 6.0 - 7.0x      │
│ 14kg (กลางคัน) : 11-12 ชั้น  (หนา 0.67x) =>  ความสูงจริง 7.3 - 8.0x      │
│ 15kg (กลางท้าย): 12-13 ชั้น  (หนา 0.67x) =>  ความสูงจริง 8.0 - 8.7x      │
│ 40kg (ท้ายรถ)  :  9-11 ชั้น  (หนา 1.0x)  =>  ความสูงจริง 9.0 - 11.0x     │
└────────────────────────────────────────────────────────────────────────┘
                                    │
                                    ▼
┌────────────────────────────────────────────────────────────────────────┐
│        Monotonic Smoothing Loop (ตรวจจับและปรับเกลี่ยความสูง)          │
│   - ตรวจสอบ if (height[i] > height[i+1])                               │
│   - ปรับเกลี่ยจำนวนมัด/กระสอบเพื่อให้ h[i] <= h[i+1] เสมอ 100%          │
└────────────────────────────────────────────────────────────────────────┘
```

### แผนการแก้ไขโค้ด:
1. **ปรับปรุง `src/utils/plannerMultiSku.ts`**:
   - กำหนดเป้าหมายจำนวนชั้นของแต่ละ SKU ในกลุ่ม 2 ตามความหนาจริง:
     - 5 กก. วางชั้นละ 4 มัด กำหนดเป้าหมาย ~6–7 ชั้น (ความสูง 6.0–7.0)
     - 14 กก. วางชั้นละ 4 กระสอบ กำหนดเป้าหมาย ~11–12 ชั้น (ความสูง 7.3–8.0)
     - 15 กก. วางชั้นละ 4 กระสอบ กำหนดเป้าหมาย ~12–13 ชั้น (ความสูง 8.0–8.7)
   - กระจายจำนวนแถวของแต่ละ SKU ตามสัดส่วนพื้นที่ เพื่อให้ได้ความสูงตามเป้าหมาย
   - นำ Monotonic Height Smoothing Algorithm มาตรวจทานทุกแถว ให้มั่นใจว่าไม่มีแถวใดสูงกว่าแถวถัดไป
2. **การทดสอบความถูกต้อง**:
   - ทดสอบกับตัวอย่างความยาวกระบะ 700 ซม. และตัวอย่าง DO 610, 620, 625 ซม.
   - ยืนยันว่า Side-View Visualizer แสดงความสูงไต่ขึ้นจากหน้าไปท้าย ไม่มีหลุมฮวบลงมา
   - ยืนยันว่าระยะท้ายรถปลอดภัย 0–15 ซม.
